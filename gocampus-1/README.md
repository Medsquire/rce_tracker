# GoCampus Bus Tracker

React-based student bus tracker for Ramachandra College of Engineering (RCEE), Eluru.

## Development

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The app includes student sign-in/demo access, a bus dashboard, live Eluru map,
bus and route details, route and trip filters, profile/settings, and navigation
drawers and dialogs. Bus locations are simulated client-side; connect a GPS or
transport API to replace the demo data before using this for operational dispatch.
